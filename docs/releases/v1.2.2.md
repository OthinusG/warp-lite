# Warpai 1.2.2

## Changes from 1.2.1

- Restore Code Review logic and entry points to the v1.0.1 baseline. The toolbar
  entry is hidden; the subsequently added SSH Review interface is removed.
- Retain SSH Project Explorer browsing, create/rename/delete actions and
  terminal-driven working directory selection.
- Retain remote file clicks into the existing code/text editor and Markdown
  preview, including relative images and linked documents.
- Preserve original remote file identity and version-checked saves across
  terminal and directory changes. Failed saves retain unsaved edits.
- Agent task review and acceptance remain available in the collaboration panel.

## Downloads

- macOS Apple silicon: `Warpai-1.2.2-macos-arm64.dmg`.
- Windows x64: `WarpaiSetup-1.2.2-windows-x64.exe`.
- Remote Linux x64: `WarpaiCompanion-2.0.0-linux-x64.run`.
- Remote macOS Apple silicon: `WarpaiCompanion-2.0.0-macos-arm64.dmg`.
- Remote Windows x64: `WarpaiCompanion-2.0.0-windows-x64-setup.exe`.

Companion remains 2.0.0 with protocol major 1. SHA-256 files accompany the
installers. macOS is ad-hoc signed; Windows installers are unsigned.

## Verification

The restored Review files match v1.0.1 byte for byte. Local focused Companion
and SFTP checks passed (23 tests). Local desktop compilation was blocked by the
missing Metal compiler. Release automation checks tagged macOS builds, all
three native Companion installations and Windows package identities before
publishing. This release is triggered without subsequent manual monitoring or
package inspection; these notes do not claim completed build/runtime acceptance.
