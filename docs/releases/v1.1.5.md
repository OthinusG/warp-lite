# Warpai 1.1.5

Warpai 1.1.5 improves local CLI agent MCP setup and cleanup.

## Agent communication

- Add a Settings action to remove Warpai MCP entries from supported installed agents.
- Recognize managed entries created by the former Warp/Warp Lite `warp-agent` bridge.
- Preserve unrelated MCP servers and report agents whose settings cannot be safely cleaned.
- Keep Codex MCP session-scoped during normal use. The communication toggle controls future Codex session injection; only the explicit cleanup action inspects a legacy persistent Codex entry.
- Preserve actionable details when an agent rejects MCP setup or cleanup.

## Downloads

- macOS Apple silicon: `Warpai.dmg`
- Windows x64: `WarpaiSetup-x64.exe`
- Remote companion installers: Linux x64, macOS Apple silicon and Windows x64

All assets are built from the `v1.1.5` tag. The release page includes SHA-256 checksums.
