# Warpai 1.5.5

Warpai 1.5.5 adds provider account usage to the native collaboration workspace.
It includes the collaboration improvements released in 1.5.1. Companion remains
4.0.0; no telemetry or bundled cloud AI is added.

## Changes from 1.5.1

- A pinned Data usage footer shows account names, Agent icons, quota percentage
  bars and verified balances. Its independent scroll area displays at most four
  rows while the collaboration history and tasks scroll separately.
- Add provider accounts and choose visible accounts in Settings > Features >
  Data usage. Use current local vendor CLI logins or connect credentials through
  OS secure storage. Account metadata never contains credentials.
- Accounts and visibility persist across projects, worktrees, tabs, panes and
  application restarts. Cached usage survives focus changes; restart restores
  configuration and retrieves fresh readings.
- Native Agent icons identify panel participants, selectors and MCP settings.
- Provider request contracts and parsing are adapted from Orca with its MIT
  notices included. Native networking, credential storage and widgets replace
  Electron dependencies. Queries are bounded and missing data stays unavailable.
- Antigravity uses a version-guarded free usage command; detected model execution
  stops subsequent polling. Expired vendor login requests reconnection.

See the [provider account guide](https://github.com/OthinusG/warpai/blob/v1.5.5/specs/agent-communication-v2/USAGE-PROVIDERS.md)
for sources and connection requirements.

- Windows x64: `WarpaiSetup-1.5.5-windows-x64.exe`.
- Remote Linux x64: `WarpaiCompanion-4.0.0-linux-x64.run`.
- Remote macOS Apple silicon: `WarpaiCompanion-4.0.0-macos-arm64.dmg`.
- Remote Windows x64: `WarpaiCompanion-4.0.0-windows-x64-setup.exe`.

SHA-256 lists cover all five installers. The existing macOS ad-hoc signing and
Windows unsigned-installer approval steps remain.
