# Warpai 1.3.1

Warpai 1.3.1 pairs the desktop app with Companion 3.1.0. Choose shared project
collaboration or coordinated parallel development in isolated Git worktrees,
locally and on your SSH host.

## Changes from 1.3.0

- The collaboration panel has a Project / Worktree switch. Project preserves
  existing messages, tasks and history for development, research and writing.
- In Worktree mode, explicitly select a Coordinator from active project Agents.
  With no active Agent, coordination actions remain unavailable. Creating a
  worktree never starts an Agent; start workers through the existing workflow
  and bind them to their actual checkouts in the panel.
- The Coordinator assigns tasks and context, collects results, requests peer
  review and selects accepted contributions for integration. Workers operate
  in their own checkouts. The Coordinator uses the ordinary Git CLI to integrate,
  verify the combined changes and create the final commit. Task acceptance does
  not automatically merge branches or publish changes.
- Local macOS/Windows and SSH Linux/macOS/Windows use the same role and task
  authority. Remote teams stay within one host/account/service. Separate clones
  and local/remote environments remain isolated; file/editor/Review roots retain
  each Agent's physical checkout.
- Selection preserves running processes and private Project history. Stale run
  events cannot adopt a replacement Agent or restore an old Coordinator; a
  replacement run requires explicit selection. Pending Project work blocks
  enrollment rather than silently migrating tasks.
- Compact worker summaries expand for branch and checkout details. Controls wrap
  in narrow panels; Coordinator and worker selectors use eligible active Agents.
- Windows background Git reads no longer allocate a console window. Native
  verification supports a cached Windows-only path for focused debugging.
- Companion 3.1.0 retains the private Git runtime, SFTP file tools and on-demand
  lifecycle. Protocol major remains 1. Bilingual README and repository About
  describe both collaboration modes in the existing product workflow.

## Downloads

- macOS Apple silicon: `Warpai-1.3.1-macos-arm64.dmg`.
- Windows x64: `WarpaiSetup-1.3.1-windows-x64.exe`.
- Remote Linux x64: `WarpaiCompanion-3.1.0-linux-x64.run`.
- Remote macOS Apple silicon: `WarpaiCompanion-3.1.0-macos-arm64.dmg`.
- Remote Windows x64: `WarpaiCompanion-3.1.0-windows-x64-setup.exe`.

Use desktop and Companion installers from this release. SHA-256 lists accompany
all five installers. macOS is ad-hoc signed and Windows installers are unsigned;
the existing operating-system approval steps still apply.

## Verification

Before the component version bump, the three-platform Companion gate passed.
Both desktops passed default/platform checks and focused application regressions.
Native capture acceptance passed with 191 images per desktop, including local
Coordinator selection, worktree creation without Agent launch and worker binding.
SSH Worktree orchestration is exercised by deterministic backend fixtures; no
paid vendor/model execution or separate SSH Worktree GUI walkthrough is claimed.
Formal release jobs verify immutable tagged source, package identity, native
installation and checksums before publication.
