# Warpai 1.5.0

Warpai 1.5.0 includes Companion 4.0.0 and improves project-based Agent
collaboration, native Git worktrees and update discovery.

## Changes from 1.3.1

- Create worktrees through Warp's existing repository/branch modal. Each new
  worktree opens a terminal tab; creating a checkout never starts an Agent.
- The main checkout and registered worktrees share one project, including their
  subdirectories. Agents join using their actual checkout. Separate clones,
  non-Git directories and SSH hosts/accounts remain isolated.
- In Worktree mode, Agents in the same checkout communicate directly. Across
  checkouts, messages go to or from the selected Coordinator. Any online Agent
  in any checkout can be Coordinator; change selection while processes and
  existing tasks continue, with unfinished-task handoff and future updates.
- Coordinator selection survives pane, tab, directory, project and panel focus
  changes. It ends when that exact Agent run exits/is revoked or Warpai closes.
  A same-name restart does not inherit Coordinator authority.
- Project lists show online Agents, filtering before pagination. Historical
  tasks and messages retain readable names for offline Agents. Non-Git folders
  keep Project communication without inheriting Worktree mode or a Coordinator.
- A prominent Collaborate entry, equal Project/Worktree buttons, consistent
  spacing and compact contextual actions make the collaboration panel clearer.
  Long checkout paths expand and wrap; Coordinator lists and details scroll.
- Settings > About adds Update and Check for updates on startup. A newer stable
  release shows a separate Download button that opens the published installer
  for the current platform. Startup checking defaults off and runs once when
  enabled. Updates never download or install automatically.
- Companion 4.0.0 carries the corrected project identity, communication mode,
  Coordinator lifetime and handoff behavior. Protocol major remains 1. Existing
  SSH file management, editing, previews, Review and private Git tools remain.
  Storage upgrades retain roles and create a pre-upgrade backup.

## Downloads

- macOS 11.0 or newer, Apple silicon: `Warpai-1.5.0-macos-arm64.dmg`.
- Windows x64: `WarpaiSetup-1.5.0-windows-x64.exe`.
- Remote Linux x64: `WarpaiCompanion-4.0.0-linux-x64.run`.
- Remote macOS 11.0 or newer, Apple silicon: `WarpaiCompanion-4.0.0-macos-arm64.dmg`.
- Remote Windows x64: `WarpaiCompanion-4.0.0-windows-x64-setup.exe`.

Use the desktop and Companion installers from this release. SHA-256 lists cover
all five installers. macOS packages are ad-hoc signed and Windows installers are
unsigned; the existing operating-system approval steps apply.

## Verification

The accepted source passes desktop default/platform builds, application unit
suites, protocol/native IPC/MCP tests and complete macOS/Windows native
walkthroughs. Each desktop capture contains 214 valid PNGs, including 24 About
states. The remote backend passes Linux/macOS/Windows and controlled SSH checks.
Formal release jobs verify immutable tagged source, component/application
versions, native installers, reinstall behavior, artwork and runtime payloads.
