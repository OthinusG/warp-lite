# Warpai 1.5.1

Warpai 1.5.1 simplifies the native collaboration panel. Companion remains 4.0.0;
its source and protocol are unchanged. Data usage is reserved for patch 1.5.5.

## Changes from 1.5.0

- An icon opens Agent collaboration from the toolbelt. Functional headings use
  icons and thin dividers with consistent spacing. The mode heading is
  `Agents Collaboration Mode`.
- Select or change Coordinator through a native dropdown. Project ownership,
  exact-run guards and persistence across panes, tabs and projects are retained.
- Manage registered local worktrees from the Worktrees section. Expand a linked
  checkout to remove it through native workspace confirmation. Main, open,
  locked, changed, untracked and ignored checkouts are protected. Removal never
  forces Git operations or deletes the branch. Creation still opens a new tab.
- Message and Assign use native dropdowns for Agents, reviewers and prerequisite
  tasks in both modes. Names remain readable while original identities are sent.
- History sits beside Message and opens a secondary view in both modes. Records
  are separated and mouse-selectable; Back restores the main view.
- Rescan agents and Remove all MCP appear only while Agent communication is on.
  Remove the nonfunctional App icon selector; retain native artwork and the
  independent Dock visibility switch.

## Downloads

- macOS 11.0 or newer, Apple silicon: `Warpai-1.5.1-macos-arm64.dmg`.
- Windows x64: `WarpaiSetup-1.5.1-windows-x64.exe`.
- Remote Linux x64: `WarpaiCompanion-4.0.0-linux-x64.run`.
- Remote macOS 11.0 or newer, Apple silicon: `WarpaiCompanion-4.0.0-macos-arm64.dmg`.
- Remote Windows x64: `WarpaiCompanion-4.0.0-windows-x64-setup.exe`.

SHA-256 lists cover all five installers. macOS packages are ad-hoc signed and
Windows installers are unsigned; the existing OS approval steps apply.
