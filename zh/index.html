{{ s.hero.note }}

01

智能体会话

Project 模式协调单个工作区；Worktree 模式在隔离的 Git 检出中并行运行多个智能体，由协调者统一调度。

每个会话都锚定在项目、分支与历史记录上——重新打开任务，不必从头再来。

02

证据与评审

任务自带验收标准。差异、测试与日志作为证据送达，每一项结果都要经过评审，再由协调者决定集成。

接受结果不会自动合并分支——最终由协调者拍板并完成提交。

03

原生终端

命令块、GPU 渲染、垂直标签、分屏、文件树与编辑器——终端工作始终在同一个窗口里完成。

命令块保留输出、退出码与可搜索的历史，长时间的任务随时翻看、随时重跑。

04

本地与远程

在远程机器上打开 SSH 项目，同一套面板如影随形——智能体、任务与评审和本地完全一致。

Companion 覆盖 Linux、macOS 与 Windows，跨平台的远程会话保持在线。
