# Superseded machine-to-machine collaboration design

Archived on 2026-10-03 before the SSH Remote product rewrite. These documents
record the previous architecture and are not active implementation instructions.
Historical code and CI evidence do not establish SSH Remote project support.

Use [the current plan](../PLAN.md) and [the cutover inventory](../CUTOVER.md).
The previous design required enrolled devices and participating native apps;
the current design manages remote project execution from one local Warpai GUI.
